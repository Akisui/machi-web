まち / machi — product website

Public site: https://akisui.github.io/machi-web/
TestFlight: https://testflight.apple.com/join/vRaaadNM
Support: https://github.com/Akisui/machi-web/issues

Static HTML, CSS and JavaScript. No framework, external font, analytics or build dependency.
Edit localized copy in source/content.json, then run: python3 source/build.py
Preview locally: python3 -m http.server 4178
GitHub Pages serves main from the repository root.

App screenshots use a demonstration library with Inori Minase events. Attendance statuses and totals are illustrative. Event titles, dates and venues are sourced from EVENTERNOTE. Event artwork belongs to its respective rights holders.
The site contains no sign-in credentials, API keys or review-contact information.
